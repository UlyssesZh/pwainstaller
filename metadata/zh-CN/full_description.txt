将常用网站安装为独立的 Android 应用。PWA Installer 直接在设备上构建并签署 APK，使用 Android 系统 WebView 显示网站。

输入网站地址以获取网页应用清单，也可以手动创建和编辑应用。为每个应用自定义名称、图标、颜色、显示模式、屏幕方向、用户代理和网址匹配规则。支持导入多个图标，包括 SVG 图片，并为图标设置 maskable 和 monochrome 等用途。

主要功能：
• 在设备上创建、安装、重新安装和导出网页应用 APK。
• 通过临时浏览器登录，并在立即安装时将浏览数据导入新应用。
• 导入、导出浏览数据，以及在生成的应用之间迁移数据。
• 导入和导出网页应用列表，包含实际图标数据。
• 支持网页应用清单中的快捷方式、文件处理程序和分享目标。
• 使用 AdGuard 过滤列表，为每个应用自定义广告拦截规则。
• 选择系统安装程序，或通过 Shizuku 静默安装。
• 管理自己的签名密钥库，并导出备份。
• 从列表菜单重新安装全部已保存应用。

每个生成的应用都有独立的 Android 包名、启动器图标、启动画面和浏览数据。生成的应用独立于 PWA Installer 运行，使用设备上安装的 WebView。内置英语和简体中文界面，支持浅色、深色主题，以及兼容设备上的动态配色。

需要 Android 5.0 或更新版本。Shizuku 安装需要 Android 7.0 或更新版本、运行中的 Shizuku 服务及授权。网页功能取决于 Android 系统 WebView；Android WebView 不提供网页 Notifications API 和 Push API。
